# AgroMercado
Prototipo de plataforma web para conectar agricultores y comerciantes
# Descripción del proyecto
AgroMercado es una propuesta de solución digital orientada a mejorar las condiciones de comercialización de pequeños productores agrícolas del municipio de Ábrego, mediante mecanismos de interacción digital entre campesinos y comerciantes.
# Prototipo de la plataforma
El prototipo fue diseñado en Figma y representa la propuesta visual de la solución tecnológica.
# Documento del prototipo
En este repositorio se encuentra el archivo PDF con las pantallas que conforman el diseño de AgroMercado.
# Objetivo
Facilitar la conexión entre productores agrícolas y comerciantes, promoviendo oportunidades de comercialización y fortaleciendo los procesos de intercambio de productos agrícolas.
